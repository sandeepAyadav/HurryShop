🛒 HurryShop – E-commerce MERN Stack App

HurryShop is a full-stack e-commerce application built using the MERN stack (MongoDB, Express, React, Node.js).
It supports AI-powered recommendations and integrates Razorpay payment gateway for seamless online transactions.

🚀 Features

🔐 User Authentication & Authorization (JWT-based)

👤 User Profile & Order History

🛍️ Product Listing, Search, and Filtering

🛒 Shopping Cart & Checkout

💳 Secure Payments using Razorpay

🤖 AI-based product recommendation system

📦 Admin Dashboard (Manage Products, Orders, Users)

🌐 Responsive Frontend with React + Tailwind/Material UI

⚡ REST API built with Node.js & Express

🗄️ Database: MongoDB (Mongoose ORM)

🏗️ Tech Stack

Frontend: React.js, Redux, Axios

Backend: Node.js, Express.js

Database: MongoDB (Mongoose)

Payments: Razorpay API

AI/ML: Recommendation Engine (TensorFlow.js / custom model)

Other Tools: Prettier, ESLint, GitHub
